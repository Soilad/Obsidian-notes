> $N$: number of gratings
### Grating Element
# $d = a+b = \frac1N$
### Grating Equation
# $d\sin\theta = n\lambda$
# $\sin\theta = nN\lambda$
### Maximum order
# $n_{max} = \lfloor \frac{d}{\lambda} \rfloor$

### Angular dispersive power
# $\frac{d\theta}{d\lambda} = \frac{n}{d\cos\theta}$

### Resolving Power
# $R = \frac{\lambda}{\Delta\lambda} = nN$
### Wavelength
# $\lambda = \frac{d\sin\theta}{n}$
