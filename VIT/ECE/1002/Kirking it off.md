### Kirchoff Voltage Law
> In a closed loop $\sum{V_i} = 0$
$$
\displaystyle
\begin{align}
0 = V_1 - IR_1 - IR_2\\
0 = V_2 - IR_3 - IR_2\\
0 = V_1 - IR_1 - IR_3 + V_2\\
\end{align}
$$
### Kirchoff Current Law
> For any node $\sum{I_i} = 0$
$$
\displaystyle
\begin{align}
i_1 = \frac{V_1-V_A}{R_1}\\
i_2 = \frac{V_A}{R_2}\\
i_3 = \frac{V_2+V_A}{R_3}\\
i_1 + i_2 + i_3 = 0
\end{align}
$$
